# Obsidian vault

This repo is an [Obsidian](https://obsidian.md) vault, synced through GitHub.

## Setup on a new device

1. Install Obsidian: https://obsidian.md/download
2. Clone this repo:
   ```bash
   git clone https://github.com/coskunuzer/ac.git
   ```
3. In Obsidian: **Open folder as vault** → choose the cloned `ac` folder.
4. When prompted, **Turn on community plugins**, then go to
   Settings → Community plugins → Browse → install **Git** (by Vinzent) and enable it.
   It's preconfigured to pull on startup, commit every 10 minutes, and pull every 10 minutes.

## Mobile
On iOS/Android, install Obsidian, then the Git plugin, and use its
"Clone an existing remote repo" command with a GitHub personal access token.
